Platform Overview

What exactly is FeynML?

FeynML is a no-code ML diagnostics platform. You upload a dataset — CSV or JSON — select a diagnostic mode, and receive a detailed failure report within seconds. No Python scripting, no configuration files, no infrastructure to manage.

Under the hood, every engine module is implemented from first principles using NumPy, SciPy, and Scikit-Learn — not black-box libraries. This means the statistical methods are transparent, auditable, and academically cited in code.

Core Capabilities

What FeynML can investigate

Six production-grade diagnostic engines, each independently testable and research-grounded.

Feature Drift Detection
Detects distribution shifts between training and production data using KS-tests, PSI scores, and Jensen-Shannon divergence across all feature types.
KS · PSI · JSD
Calibration Audit
Measures how well model probability scores match observed frequencies. Computes ECE, MCE, Brier score, and reliability diagrams with actionable severity ratings.
ECE · MCE · Brier
Fairness Audit
Assesses model performance across sensitive demographic groups. Flags disparate impact, equalized odds violations, and demographic parity gaps.
SPD · DI · EOD
Label Noise Detection
Surfaces inconsistent, mislabeled, or ambiguous annotations that degrade model learning. Uses confidence-weighted disagreement and cross-validation signals.
Confidence · CV
Leakage Detection
Flags features with suspiciously high predictive power that may indicate target leakage, future-data contamination, or ID-like columns leaking ground truth.
Mutual Info · SHAP
Missingness Analysis
Evaluates missing value patterns for MCAR, MAR, and MNAR signals. Visualizes coverage gaps and identifies features with structurally problematic missingness.
MCAR · MAR · MNAR

Guiding Philosophy

Why "Feyn"?

"If you can't explain it simply, you don't understand it well enough."
— Richard P. Feynman

Richard Feynman's signature method was deceptively simple: to understand any complex phenomenon, explain it to a beginner. If you can't, you have a gap in your own model of reality. FeynML applies this exact principle to machine learning systems.

Modern ML failures are often invisible. A drift goes undetected because no one ran a PSI check. A calibration error persists because the team trusted AUC alone. A leaky feature ships to production because manual EDA is too slow. FeynML automates the investigation layer — the part that requires deep statistical understanding — and surfaces results in plain language anyone can act on.

The Feynman Technique applied to ML: understand deeply, explain clearly, fix precisely.
